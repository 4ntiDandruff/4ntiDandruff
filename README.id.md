## 🛠️ Filosofi & Latar Belakang

Saya adalah teknisi hardware sirkuit bersertifikasi dan pengelola **Megapass Intra Solusindo**, laboratorium diagnostik & perbaikan elektronik tingkat komponen (*board-level repair*) di Sidoarjo, Jawa Timur. Lingkungan kerja harian saya adalah *hot air rework station*, multimeter digital, osiloskop, dan skematik *boardview* — melacak jalur korslet, menganalisis *voltage drop*, dan menyolder IC mikroskopis pada ponsel & motherboard laptop.

Pengembangan perangkat lunak (*software engineering*) bagi saya bukan sekadar teori akademis. Setiap alat lahir dari hambatan nyata di meja servis:
- Lelah mem-flash chip BIOS via baris perintah CLI yang rumit $\rightarrow$ Membangun **CH341A Flasher GUI**.
- Lelah menghapus aplikasi bawaan (*bloatware*) puluhan ponsel secara manual $\rightarrow$ Membangun **ADB Uninstaller**.
- Hijrah dari Windows ke **Kubuntu (KDE 6 / Wayland)** dan terbentur isolasi file dialog $\rightarrow$ Membangun **Auto-Extract Downloads** (*event-driven Linux daemon*).

> **Prinsip Teknisi Hardware**: *"Jika one-liner shell atau native daemon mampu menyelesaikan masalah, itulah jawabannya. Tanpa bloatware, 0% CPU polling saat standby, dan murni logika sebab-akibat."*

## ⚡ Proyek Rekayasa Unggulan

### 🚀 [Auto-Extract Downloads for Linux](https://github.com/4ntiDandruff/auto-extract-downloads)
**Daemon Ekstraksi Arsip Event-Driven dengan 9 Lapis Sekring Pengaman**  
Mengatasi hambatan dialog *Import File* pada Linux Desktop (KDE/GNOME). Menggunakan sinyal interupsi kernel (`inotify`) untuk mengekstrak `.zip`, `.rar`, `.7z` secara instan dengan **0% CPU idle** dan RAM hanya **~1.5 MB**. Dilengkapi **Self-Compress Loop Guard**, proteksi batas sisa disk, dan saklar dinamis CLI (`auto-extract limit/depth`).  
`Shell` • `inotify-tools` • `Systemd User Unit` • `libnotify` • `unar/7z`

### 🔌 [CH341A BIOS Flasher Tauri](https://github.com/4ntiDandruff/CH341A-BIOS-Flasher-Tauri)
**Aplikasi GUI Desktop Profesional untuk Hardware Programmer CH341A USB**  
Membungkus engine `flashrom` untuk kebutuhan meja servis laptop & PC. Menghilangkan hafalan parameter CLI, mendeteksi tipe IC secara visual, memverifikasi hasil baca/tulis, dan memastikan proses flash ROM aman.  
`Tauri v2` • `Rust` • `TypeScript` • `Python` • `flashrom`

### 🤖 [ADB Uninstaller](https://github.com/4ntiDandruff/adb-uninstaller)
**Debloater Android Cerdas dengan Bantuan AI & Resolusi Paket Otomatis**  
Aplikasi meja servis ponsel untuk menghapus aplikasi bawaan secara massal (*batch processing*) pada beberapa perangkat USB sekaligus, dilengkapi *knowledge-base* pintar untuk menjaga keamanan sistem Android.  
`Tauri v2` • `React` • `TypeScript` • `Android Debug Bridge (ADB)`

### 🌐 [kalenderia.my.id](https://github.com/4ntiDandruff/kalenderia.my.id)
**Mesin Percetakan & Sistem Workshop Kalender Presisi Sidoarjo**  
Aplikasi produksi komersial cetak kalender di Sidoarjo. Dibangun dengan filosofi *no-build* untuk respon instan tanpa bloat JavaScript berlebih.  
`Python Flask` • `HTMX` • `Tailwind CSS v4` • `Jinja2`
