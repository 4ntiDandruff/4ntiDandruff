## 🔧 About Me & The Repair Bench

I am a certified electronics technician and owner of **Megapass Intra Solusindo** in Sidoarjo, Indonesia. My daily work centers around the repair bench: hot air rework stations, digital multimeters, dual-channel oscilloscopes, and boardviews — diagnosing motherboard shorts, tracking power rail drops, and replacing micro-scale ICs on laptops and mobile devices.

I bridge deep circuit-level hardware diagnostics with automated systems engineering:
- **Low-Level Hardware**: Manual terminal commands for flashing laptop BIOS chips were repetitive and error-prone → Engineered **CH341A Flasher GUI**.
- **AI Agent Automation**: Orchestrating autonomous agent pipelines with strict behavioral directives for automated verification, monitoring, and code generation.
- **Linux Engineering**: Migrated to Linux (**Kubuntu 26.04**) and built **Auto-Extract Downloads**, an event-driven system daemon equipped with 9 safety fuses and 0% CPU overhead.

> **Bench Rationale**: *"If a simple shell script, native daemon, or circuit jumper solves the problem with 0% CPU overhead, that is what ships to production. No bloat, no needless abstractions."*

## ⚡ Production Projects Tested on the Bench

### 🚀 [Auto-Extract Downloads for Linux](https://github.com/4ntiDandruff/auto-extract-downloads)
**Event-Driven Archive Extraction Daemon for Linux Desktop (KDE/GNOME)**  
Eliminates archive extraction friction during file-picker imports in Linux. Operates seamlessly via kernel events (`inotify`) with **0% idle CPU** and **~1.5 MB RAM**. Features 9 built-in safety fuses (self-compression loop guard, disk space cutoff, image protection).  
`Shell` • `inotify-tools` • `Systemd User Unit` • `libnotify` • `unar/7z`

### 🔌 [CH341A BIOS Flasher Tauri](https://github.com/4ntiDandruff/CH341A-BIOS-Flasher-Tauri)
**Desktop GUI for the CH341A USB Programmer**  
Wraps the `flashrom` engine for laptop repair benches. Eliminates the need to memorize CLI flags, auto-detects IC models, verifies read/write integrity, and prevents accidental EEPROM corruption.  
`Tauri v2` • `Rust` • `TypeScript` • `Python` • `flashrom`

### 🤖 [ADB Uninstaller](https://github.com/4ntiDandruff/adb-uninstaller)
**Android Debloater for Technician Workstations**  
Batch-removes vendor bloatware across USB-connected customer devices with safety classifications to prevent bricking devices.  
`Tauri v2` • `React` • `TypeScript` • `Android Debug Bridge (ADB)`

### 🌐 [kalenderia.my.id](https://github.com/4ntiDandruff/kalenderia.my.id)
**Production Printing Engine & Workshop System**  
Commercial web application for calendar printing in Sidoarjo. Built with a strict no-build philosophy (Flask + HTMX) for instant page loads.  
`Python Flask` • `HTMX` • `Tailwind CSS v4` • `Jinja2`
