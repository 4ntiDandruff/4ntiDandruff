## Salam Kenal dari Meja Servis

Halo! Saya **Hizam Nahari**, teknisi perangkat keras asal Sidoarjo, Jawa Timur. Hari-hari saya dihabiskan di meja servis bergelut dengan solder, blower uap, multitester, injeksi tegangan, skema boardview, dan bongkar-pasang komponen motherboard laptop maupun ponsel.

Di sela-sela kesibukan fisik ini, saya mendalami sistem Linux, membangun otomasi untuk mempercepat alur kerja bengkel, dan merancang **software mandiri berprinsip zero-bloat**.

Bagi saya, melacak jalur tegangan yang korslet di motherboard punya kepuasan yang sama persis seperti menyusun logika kode program: sama-sama menuntut ketelitian membaca skema, sabar mencari akar masalah, dan kepuasan melihat sistem kembali hidup normal dengan stabil.

## Proyek & Perkakas Nyata dari Meja Servis

Seluruh repositori di akun ini bukan sekadar kode latihan, melainkan perkakas otomasi, modul keahlian, dan utilitas yang lahir langsung untuk menyelesaikan masalah nyata di meja kerja ruko:

### [Zero-Bloat Skills](https://github.com/4ntiDandruff/zero-bloat-skills)
**31 Modul Keahlian Tingkat Sirkuit Meja Servis, Linux Bare-Metal, dan Multi-Agent AI Gateway**
* **Masalah Lapangan**: Mengelola server bengkel, alat flash BIOS, streaming CCTV ruko, dan asisten AI di PC tua hemat daya (Core i3-3240) tanpa bikin memori bengkak.
* **Solusi Teknis**: Kumpulan 31 modul SOP teknisi teruji lapangan yang disinkronkan langsung ke agen AI (Google Antigravity, Claude Code, OMP, OpenCode, Codex). Zero build-step, tanpa beban node_modules, hemat RAM di bawah 50MB.
* **Dampak Praktis (*Yang Artinya...*)**: *Otomasi bengkel harian jalan senyap di latar belakang tanpa bikin komputer lemot atau kipas meraung.*  
`Linux Bare-Metal` • `AI Agent Skills` • `Zero-Bloat Architecture` • `Bash/Python`

### [Mobile View Browser Extension](https://github.com/4ntiDandruff/mobile-view)
**Ekstensi Browser Workbench untuk Pratinjau Tampilan Mobile Sekali Klik**
* **Masalah Lapangan**: Mode responsive bawaan browser (F12) terasa kaku dan tidak memberi gambaran nyata jangkauan jempol di layar smartphone.
* **Solusi Teknis**: Ekstensi browser Chromium Manifest V3 murni tanpa bundler rumit, lengkap dengan bingkai smartphone presisi dan reload otomatis via kernel inotify Linux.
* **Dampak Praktis (*Yang Artinya...*)**: *Memudahkan pengujian tata letak web di layar ponsel langsung dari monitor desktop tanpa perlu bolak-balik meraih HP fisik.*  
`JavaScript` • `Chromium Manifest V3` • `Tailwind CSS` • `HTML5`

### [Windows Optimizer Toolkit](https://github.com/4ntiDandruff/windows-optimizer)
**Kumpulan Skrip Pembersih Sistem Ringan untuk PC Pelanggan**
* **Masalah Lapangan**: Hampir setiap laptop pelanggan yang masuk bengkel tersiksa oleh tumpukan file sampah, sisa cache, dan belasan aplikasi startup yang tidak jelas gunanya.
* **Solusi Teknis**: Kumpulan skrip native PowerShell dan Batch murni untuk membuang file sementara serta mematikan startup siluman dengan aman tanpa utak-atik registry berisiko.
* **Dampak Praktis (*Yang Artinya...*)**: *Servis pembersihan sistem tuntas dalam hitungan detik tanpa perlu memasang aplikasi cleaner pihak ketiga yang rawan disusupi iklan.*  
`PowerShell` • `Batch` • `Windows Utilities`

### [CH341A BIOS Flasher Tauri](https://github.com/4ntiDandruff/CH341A-BIOS-Flasher-Tauri)
**Antarmuka Desktop Ringkas untuk Alat Flash EEPROM USB**
* **Masalah Lapangan**: Mengetik parameter panjang utilitas flashrom di terminal Linux rawan salah ketik saat teknisi buru-buru mem-flash chip BIOS fisik.
* **Solusi Teknis**: Antarmuka desktop visual berbasis Tauri v2 (Rust) yang membungkus CLI flashrom menjadi tombol-tombol kendali yang jelas dan aman.
* **Dampak Praktis (*Yang Artinya...*)**: *Pemeriksaan tipe chip IC, verifikasi backup dump BIOS, dan penulisan firmware jadi cepat serta minim salah klik sebelum chip disolder kembali ke board.*  
`Tauri v2` • `Rust` • `TypeScript` • `flashrom`

### [Auto-Extract Downloads for Linux](https://github.com/4ntiDandruff/auto-extract-downloads)
**Ekstraksi Arsip Otomatis Berbasis Event Kernel Linux**
* **Masalah Lapangan**: Bolak-balik klik kanan untuk mengekstrak arsip zip/rar skema boardview atau file driver hasil unduhan sering memutus konsentrasi kerja servis.
* **Solusi Teknis**: Daemon POSIX Shell berbasis inotify-tools yang memantau folder Downloads dengan beban 0% CPU, langsung mengekstrak berkas secara otomatis begitu proses unduh tuntas.
* **Dampak Praktis (*Yang Artinya...*)**: *Berkas skematik atau BIOS langsung terurai rapi di folder siap pakai, tangan teknisi tidak perlu lepas dari keyboard.*  
`POSIX Shell` • `inotify-tools` • `Systemd User Unit`

### [ADB Mobile Debloater](https://github.com/4ntiDandruff/adb-uninstaller)
**Antarmuka Manajemen Aplikasi Android via Sambungan USB**
* **Masalah Lapangan**: Memori internal ponsel pelanggan (Samsung, Xiaomi, Oppo, Vivo) sering penuh sesak oleh aplikasi bawaan pabrik yang tidak bisa dicopot lewat menu setelan biasa.
* **Solusi Teknis**: Utilitas desktop berbasis Tauri v2 via Android Debug Bridge (ADB) dengan daftar filter aman (whitelist/blacklist paket) tanpa mewajibkan root.
* **Dampak Praktis (*Yang Artinya...*)**: *Kapasitas penyimpanan dan RAM ponsel kembali lega tanpa risiko sistem crash atau bootloop.*  
`Tauri v2` • `TypeScript` • `Android Debug Bridge (ADB)`

## Fondasi Teknologi & Alat Kerja

Setiap teknologi yang saya gunakan dipilih atas dasar kepraktisan, transparansi, dan keandalannya di lapangan:

| Bidang | Alat | Alasan & Manfaat Nyata di Lapangan |
|---|---|---|
| **Sistem Operasi** | Linux (Ubuntu / Debian) | *Sistem kerja utama. Stabil, transparan, dan memberi kendali penuh tanpa proses latar belakang tersembunyi.* |
| **Bahasa Skrip** | Bash / Shell & Python | *Amunisi utama otomasi harian, skrip pengolah data cepat, dan penghubung antar-layanan.* |
| **Backend & Web** | Python FastAPI & SQLite | *Alur kode lugas, mudah didebug, dan database SQLite WAL sangat tangguh terhadap insiden mati lampu mendadak tanpa server DB berat.* |
| **Tampilan Web** | HTML5, Tailwind CSS, Alpine.js | *Antarmuka responsif tanpa proses build rumit (zero build-step), langsung edit di file dan render instan di browser.* |
| **Version Control** | Git & GitHub | *Pencatatan riwayat perubahan terstruktur, kontrol versi sistem ruko, dan repositori terbuka.* |

## Kisah di Balik Nama MEGAPASS

Bengkel servis yang saya rintis di Sidoarjo bernama **Megapass Intra Solusindo**. Nama ini membawa makna personal yang selalu saya rawat:

* **Mega**: Panggilan istri tercinta, alasan di balik ketekunan, ketulusan, dan rasa tanggung jawab saya setiap hari.
* **PASS**: Kata paling melegakan di meja teknisi. Tulisan **PASS** dengan kotak hijau di layar pengujian adalah bukti sah bahwa perangkat yang rusak sudah sembuh total, seluruh fungsi perangkat keras lolos uji kelayakan, dan siap diserahkan kembali kepada pemiliknya.

Prinsip ini yang tertanam di setiap pekerjaan saya: baik saat menyolder kaki komponen mikro maupun merancang baris logika kode, semuanya dikerjakan seteliti mungkin sampai layak dinyatakan **PASS**.
